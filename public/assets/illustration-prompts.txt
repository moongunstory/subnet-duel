Subnet Duel image generation prompts for ComfyUI
===============================================

Art direction
-------------
Concept: arcade subnetting battle, falling IP blocks, cyber classroom arena, fast but readable.
Mood: competitive, playful, polished, not too dark, not horror, not military.
Palette: near-black interface base with neon green, cyan, amber, coral accents.
Style: high-quality game key art, semi-realistic illustration with clean graphic shapes, sharp UI-like geometry.
Avoid: text in image, logos, cluttered cable mess, overly blue/purple palette, beige fantasy look.

1. Main hero key art
--------------------
Prompt:
Arcade game key visual for a web game called Subnet Duel, two students or young network engineers facing each other across a glowing digital arena, IP address blocks and CIDR tiles falling like puzzle blocks, subnet masks and network routes represented as abstract glowing panels, energetic competitive mood, clean readable composition, neon green cyan amber coral accents, dark tech arena background, high-quality semi-realistic game illustration, sharp lighting, polished UI game poster, no readable text, no logo

Recommended output:
public/assets/subnet-duel-hero.webp
Aspect ratio: 16:9 or 21:9
