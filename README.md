# Subnet Duel

IP 주소와 CIDR이 블록처럼 떨어지는 실시간 서브넷 계산 배틀 MVP입니다. 닉네임을 입력하면 로비에 입장하고, 경쟁 매칭 또는 싱글 연습을 바로 시작할 수 있습니다.

## 실행

```bash
npm start
```

브라우저에서 `http://localhost:3000`에 접속하면 됩니다.

## 현재 기능

- 1v1 경쟁 매칭: 매칭 전에 CIDR을 고르지 않고 랜덤 문제 세트로 바로 시작합니다.
- 싱글 연습: 경쟁전이 아닌 혼자 10문제를 풀 수 있습니다.
- 실시간 상태판: 접속자, 점수, 정답률, 진행률을 볼 수 있습니다.
- 전체 채팅: 로비 좌측 하단에서 접속자끼리 메시지를 주고받습니다.
- 효과음: 버튼, 매칭, 정답, 오답, 종료 상황에 WebAudio 기반 효과음을 재생합니다.
- 문제 세트: 같은 경기의 두 플레이어에게 같은 10문제가 제공됩니다.
- 상대 답안 블라인드: 상대의 진행률과 문제 상태는 보이지만 답안은 흐리게 처리됩니다.

## 규칙

- 문제는 매 경기마다 새로 생성됩니다.
- 점수는 문제 유형과 CIDR 난이도에 따라 달라집니다.
- 정답이면 30초 이내 제출 속도에 따라 최대 20% 보너스를 받습니다.
- 승자는 총점, 정답률, 평균 제출 시간 순서로 결정됩니다.
